## Decisions for this card (supervisor)
- **weaponsLocked.** On the instance class in `Instance.gd`: `static func weapons_locked_for(p_map_name: String, p_safezone: bool) -> bool` = `p_safezone or p_map_name != GameConst.MAP_LOOTY_BAY`, and `func weapons_locked() -> bool` = `weapons_locked_for(map_name, safezone)`. `PlayerService.fire` and `PlayerRoleController.can_attack_roles` both call it instead of their inline condition. Hud ctx `weapons_locked` = `_instance.weapons_locked()` when `_instance` is valid, else false; snapshot `weaponsLocked = bool(ctx.get("weapons_locked", false))`.
- **surrenderAvailable (server-computed, state in PlayerService).**
  - `static func surrender_block(in_transfer: bool, has_player: bool, map_name: String, role: int, life: int, has_cop: bool) -> String`: `""` when all pass, else in this order `"silent"` (in transfer, no player, or not ALIVE), `"map"` (not LootyBay), `"role"` (not CRIMINAL), `"no_cop"`.
  - `func _surrender_check(peer_id: int) -> Dictionary` returning `{"block": String, "cop": Node or null}`; it calls `_find_surrender_cop` only after the silent/map/role checks pass (raycasts only for criminals in LootyBay).
  - `func surrender_available(peer_id: int) -> bool` = `_surrender_check(peer_id).block == ""`.
  - `surrender` calls `_surrender_check` once: `map`/`role`/`no_cop` send the three existing rejection texts verbatim, `silent` returns quietly, `""` uses `cop` as today.
  - `func tick_surrender(now_ms: int) -> void`: return while `now_ms < _next_surrender_check_ms`; then `_next_surrender_check_ms = now_ms + GameConst.SURRENDER_CHECK_INTERVAL_MS`; for each id in `peer_ids()`: `var v := surrender_available(id)`; if `v != bool(_surrender_sent.get(id, false))`, send `client_surrender_available` `[v]` to that peer through the host's client-RPC path (as PlayerService sends other owner RPCs) and store `v`. `_surrender_sent.erase(peer_id)` next to `_last_fire_ms.erase`.
  - `ServerManager._process` calls `_players.tick_surrender(_now_ms())`. Declare `@rpc("authority", "call_remote", "reliable") func client_surrender_available(available: bool)` next to `client_mask_channel`; it emits `surrender_available_changed(available: bool)`.
  - Client: Main `_on_surrender_available(on)` -> `_hud.set_surrender_available(on)`; snapshot `surrenderAvailable` = `bool(ctx.get("surrender_available", false))` and role CRIMINAL and life ALIVE. Reset to false in `show_lobby`.
- **surrenderKey.** Snapshot `surrenderKey` = `InputBindings.label_for(InputBindings.code_for("bind_surrender"))`.
- **Key labels.** `InputBindings.label_for(code: String) -> String`: copy the `NAMED` table from `ui/web/src/features/settings/format.ts` verbatim into `const _LABELS`; `Key[A-Z]` -> the letter, `Digit N` -> the digit, `Numpad N` -> `Num N`, anything else -> the code; split on `+` and keep the prefixes (`Ctrl+KeyB` -> `Ctrl+B`). Deliberate deviation from the web: `""` -> `GameConst.UNBOUND_KEY_LABEL` (`"—"`). `Hud.interact_of` maps each prompt key letter through `PROMPT_KEY_ACTIONS = {"E": "bind_interact", "V": "bind_smash", "R": "bind_revive", "X": "bind_finish", "C": "bind_cuff", "T": "bind_search_take", "Q": "bind_search_close", "H": "bind_surrender", "F": "bind_mask", "G": "bind_cop_duty"}` to `label_for(code_for(action))` (an unbound action shows `—`); a letter not in the map stays as written. Replace the card-10 `ponytail` comment there.
- **heistAlert (client-side, from the existing scoped RPC).** `loot_id` values are item types (`"jewelry"`, `"electronics"`, `"cash_box"`, default `"valuables"`); each crate is looted once per instance and an instance change clears the alert, so deduping by `loot_id` is fine.
  - `Instance.gd`: signal `loot_alert(loot_id: String, world_position: Vector3)`; in `client_loot_alert`, after the print, `if loud: loot_alert.emit(loot_id, world_position)`.
  - Main: in `client_show_instance`, `instance.loot_alert.connect(_on_loot_alert)`; `_on_loot_alert(loot_id, _pos)` -> `_hud.add_heist_alert(loot_id, _client_now_ms())`.
  - Hud: `var _heist: Dictionary = {}` (`{"id", "location", "started_ms"}`). `add_heist_alert(loot_id, now_ms)`: ignore only when the id matches and `now_ms < started_ms + HEIST_ALERT_ACTIVE_MS`; otherwise replace (restarts the toast). `location` = `Hud.item_label(loot_id)`. In `_process`, next to `prune_notifications` (before the `_page_ready` return), clear `_heist` once `now_ms >= started_ms + HEIST_ALERT_ACTIVE_MS`. `set_instance(instance)`: `if instance != _instance: _heist = {}` before assigning. `show_lobby` clears it.
  - `static func heist_alert_view(heist: Dictionary, now_ms: int) -> Variant`: `{}` or expired -> null; else `{"id", "label": "Heist alert", "location": location or null when "", "active": true, "toastSecondsLeft": max(0, ceili((started_ms + HEIST_TOAST_MS - now_ms) / 1000.0))}`. ctx key `heist` (`_heist`); `snapshot` sets `heistAlert` from it.
  - `# ponytail:` no server clear event exists; the active line expires locally after `HEIST_ALERT_ACTIVE_MS`.
- **channels (server tells the downed target).**
  - `ChannelTimer.REASONS` gets `"pressed_again"` (update `test_channel_timer.gd` `test_reason_contract`).
  - `_start_channel`: after `timer.start`, for revive and finish only: `_send_client(target_peer, "client_downed_channel", [kind, int(duration * 1000.0)])` (use DownedService's existing client-send helper; name may differ, reuse it).
  - `func _channel_ended(record: Dictionary) -> void`, called from `_on_channel_completed`, `_on_channel_cancelled` and the stale-record branch of `_cancel_record`, after the record is erased: for revive/finish, if another record with the same kind and target is still in `_channels`, re-send `[kind, int(timer.time_left() * 1000.0)]` for it; otherwise send `[kind, 0]`. Cuff and search send nothing.
  - Press again: `func _find_channel(actor: int, target: int, kind: String) -> Dictionary` (the record or `{}`). First statement of `request_revive`/`request_finish`/`request_cuff`: `var running := _find_channel(actor_peer, target_peer, KIND_X); if not running.is_empty(): _cancel_record(running, "pressed_again"); return` (before `_actor_is_busy` and the checks). The actor gets "Action cancelled (pressed_again)" from the existing cancel message. Any other running channel keeps "You are already channelling".
  - ServerManager: `@rpc("authority", "call_remote", "reliable") func client_downed_channel(kind: String, duration_ms: int)` next to `client_mask_channel`; emits `downed_channel_changed(kind: String, duration_ms: int)`. Main `_on_downed_channel(kind, ms)` -> `_hud.set_downed_channel(kind, ms, _client_now_ms())`; connect both new ServerManager signals next to the existing connects in `_start_client`.
  - Hud: `var _channels: Dictionary = {}` (kind -> `{end_ms, duration_ms}`); `set_downed_channel`: `duration_ms > 0` stores, 0 erases. `var _last_life: int = -1`; in `_process` clear `_channels` only on the DOWNED -> not-DOWNED transition (a start may arrive before the DOWNED sync). `show_lobby` clears it. ctx key `channels`. `static func channels_view(channels: Dictionary, life: int, now_ms: int) -> Variant`: null unless DOWNED, else `{"revive": entry or null, "finish": entry or null}`, entry `{"secondsLeft": max(0, ceili((end_ms - now_ms) / 1000.0)), "durationSeconds": duration_ms / 1000.0}`.
- New GameConst: `SURRENDER_CHECK_INTERVAL_MS: int = 250`, `HEIST_TOAST_MS: int = 8000`, `HEIST_ALERT_ACTIVE_MS: int = 90000`, `UNBOUND_KEY_LABEL := "—"`.

## Rules
- Server authority: the client only displays what the server sends (weapons lock uses the same shared static rule). `features/` never import `autoload/` (use the injected host / callables as existing services do); `lib/` imports nothing project-specific; `ui/` never references `ServerManager`. Services own state and are ticked from `ServerManager._process` with an injected `now_ms`. No magic numbers.
- Tests extend `TestCase`, mirror the source tree, no setup/teardown hooks: compute values, reset static state (`InputBindings.clear()`), free nodes, then assert.
